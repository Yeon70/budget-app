## 1. 목표

- **10월 안에 실제로 기록을 시작해요.** → 0~3단계를 먼저 끝내요.
  - 3단계까지 끝나면 입력, 내역, 예산, 홈이 다 되니까 바로 쓸 수 있어요.
- 4단계부터는 **쓰면서** 하나씩 추가해요.

## 2. 진행 방식

단계마다 아래를 반복해요.

```
① Claude가 만듦
   ↓
② 맥북 미리보기(localhost:3000)로 같이 확인 → 고칠 것 고침
   ↓
③ Claude가 커밋
   ↓
④ 내가 GitHub Desktop에서 Push
   ↓  (1~2분 뒤 자동 배포)
⑤ 아이폰에서 배포 주소로 QA (아래 단계별 체크리스트)
   ↓
⑥ OK → 다음 단계
```

- 단계가 크면 중간에 나눠서 보여줄게요.
- QA하다 이상한 점은 스크린샷과 함께 말해주면 돼요.

## 3. 단계별 계획

### 0단계 — 준비
- [ ] Supabase 새 프로젝트 만들기 (지역: 서울) — 화면 보며 같이
- [ ] 표 5개 + 보안 잠금(RLS) 만들기 — Claude가 SQL 준비, 내가 붙여넣고 실행
- [ ] Authentication 설정: 이메일 가입, 사이트 주소 등록
- [ ] 폴더 뼈대, 색 변수, 글꼴, 하단 탭바
- [ ] GitHub Pages 켜기 + 첫 배포

**QA**: 아이폰에서 배포 주소를 열면 하단 탭바가 있는 빈 앱이 보인다.

### 1단계 — 로그인
- [ ] 로그인 / 가입 / 인증 메일 / 비밀번호 찾기
- [ ] 로그인 유지, 로그아웃

**QA**: 가입 → 메일 인증 → 로그인 → 앱을 닫았다 열어도 로그인 유지 → 로그아웃

### 2단계 — 입력 + 내역 ⭐
- [ ] 입력 화면 (수입/지출, 금액 패드, 소항목 아이콘, 날짜, 결제수단, 메모)
- [ ] 저장 후 이어서 입력 (날짜·결제수단 유지)
- [ ] 내역: 달력 + 아래 그날 내역, [이번 달 전체], 골라보기
- [ ] 누르면 수정, 밀어서 삭제

**QA**: 하루치 지출 3건 입력 → 달력에 금액 표시 → 1건 수정, 1건 삭제 → 맥북에서 열어도 똑같이 보임

### 3단계 — 예산 + 홈 ⭐ (여기까지 끝나면 사용 시작)
- [ ] 예산 입력 화면 (지난달 값 흐리게 참고)
- [ ] 홈 요약 카드: 남은 예산, 수입/지출, 사용률 바, 상태 + 범고래 + 메시지
- [ ] 오늘 쓸 수 있는 돈
- [ ] 수입/지출 묶음 접기·펼치기, 소항목 바 (색 5단계, 남은 돈, 초과 표시)
- [ ] 달 이동 (화살표, 밀기)

**QA**: 10월 예산 입력 → 지출 입력할 때마다 바 색, 상태, 범고래가 맞게 바뀜 → 예산 초과 표시 확인

### 4단계 — 고정 항목 자동 기록
- [ ] 설정: 자동/수동, 매달 며칠·얼마·결제수단
- [ ] 앱을 열 때 자동 기록, "예정 25일" → "완료 ✓"
- [ ] 중복 기록 방지, 지운 자동 기록은 다시 안 생김

**QA**: 오늘 날짜로 자동 규칙 만들기 → 바로 기록됨 → 앱 다시 열어도 1건만 있음

### 5단계 — 통계
- [ ] 도넛(소항목 비율), 예산 vs 실제, 지난달 비교
- [ ] 결제수단별, 저축 쌓이기, 1년 요약

### 6단계 — 내보내기
- [ ] 엑셀: 기간 선택 → 월별 탭
- [ ] B5 PDF: 큰 분류 요약 + 도넛

**QA**: 엑셀을 아이폰·맥북·구글시트에서 열어보기, B5 PDF 인쇄 미리보기 확인

### 7단계 — 외화
- [ ] 통화 선택(₩ / $ / ¥), 쓴 날짜 환율로 원화 자동 계산, 직접 수정

### 8단계 — 마무리
- [ ] 월말 칭찬·위로 팝업
- [ ] 설정: 소항목 켜기/끄기·순서, 카드사·은행 순서
- [ ] 회원 탈퇴, 개인정보 안내
- [ ] 이미지 정리 (범고래 조각 지우기, 아이콘 크기·위치 맞추기)
- [ ] 데이터베이스가 잠들었을 때 안내

### 9단계 — 앱 완성도
- [ ] PWA: 홈 화면 아이콘, 전체 화면, 앱 이름
- [ ] 다크모드 (아이폰 설정 따라감)

### 2단계 기능 (나중에)
- [ ] 여러 줄 붙여넣기 자동 분류 (AI 없이) — [02-design 13번](02-design.md)
