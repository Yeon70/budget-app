# 01. 아이디어 정리 — 심플가계부

> 상태: ✅ 확정 (2026-10-04)
> 작성일: 2026-10-04

---

## 1. 한 줄 소개

**월마다 소항목별 예산을 정하고, 은행 앱을 보며 직접 입력한 지출이 예산의 몇 %인지 색깔 바로 한눈에 보는 나만의 가계부.**

## 2. 목적

- 예산 안에서, 또는 예산보다 **덜** 쓰는 습관 만들기
- 예산보다 적게 쓰면 **칭찬**해주기 (남은 돈은 다음 달로 넘기지 않음)

## 3. 사용 환경

| 항목 | 내용 |
|---|---|
| 사용자 | 나 + **누구나 가입 가능** (각자 자기 가계부만 보임) |
| 주 기기 | 아이폰 (가끔 맥북) |
| 입력 습관 | 하루 한 번, 또는 주말에 몰아서 |
| 은행 연동 | 하지 않음 — 은행 앱을 보고 직접 입력 |
| 데이터 저장 | Supabase (아이폰과 맥북에서 같은 데이터를 봄) |
| 로그인 | 이메일 + 비밀번호 (가입, 비밀번호 찾기, 탈퇴) |
| 배포 | GitHub Pages (저장소: `Yeon70/budget-app`) |

> 💡 **몰아서 입력**한다는 점은 입력 화면 설계에 반영해요.
> - 날짜를 쉽게 바꿀 수 있어야 해요.
> - 한 건을 저장한 뒤 바로 다음 건을 이어서 입력할 수 있어야 해요.

## 4. 카테고리 구조

**수입**과 **지출** 두 가지가 있고, 각각 고정/변동으로 나뉘어요. 그 아래에 소항목이 들어가요. **소항목은 앱이 정해둔 목록에서 켜고 끄는 방식**이에요. 이름을 직접 만들지는 않아요. (전체 목록은 [03-data.md](03-data.md))

| 큰 분류 | 기본 소항목 (예시) | 예산 바 |
|---|---|---|
| 수입 · 고정 수입 | 월급 | ❌ 금액만 표시 |
| 수입 · 변동 수입 | 부수입, 용돈, 중고판매 | ❌ 금액만 표시 |
| 지출 · 고정 지출 | 월세, 통신비, 구독료, 보험, **적금💰** | ✅ |
| 지출 · 변동 지출 | 식비, 간식비, 여가생활, 선물, 건강, 뷰티, **투자💰** | ✅ |

- 저축/투자는 "나가는 돈"이라서 **지출 안의 소항목**으로 넣어요.
- 대신 소항목마다 **"저축 항목" 표시(💰)**를 켤 수 있어요.
  - 표시된 항목의 바는 **초록색 하나**로 채워요. (많이 채울수록 좋은 것)
  - 통계에서 저축이 **차곡차곡 쌓이는 모습**을 따로 보여줘요.

## 5. 예산

- 예산은 **소항목마다** 정해요. (예: 식비 40만, 간식 5만)
- 예산은 **매달 새로 입력**해요.
- 한 달 = 그 달 **1일 ~ 말일**
- 남은 예산은 다음 달로 넘어가지 않아요.
- 그 달 지출이 예산 이하로 끝나면 칭찬 메시지를 보여줘요. (예: "🎉 식비 3만 원 아꼈어요!")

## 6. 고정 지출 자동 처리

- 고정 지출 항목마다 **자동 / 수동**을 고를 수 있어요. 나중에 바꿀 수도 있어요.
  - **자동**: 항목마다 정한 날(예: 월세 25일)에 기록돼요. 고정 수입(월급)도 똑같이 자동으로 할 수 있어요.
  - **수동**: 내가 직접 입력해요.

## 7. 지출(수입) 한 건 입력 정보

| 정보 | 필수 | 예시 |
|---|---|---|
| 날짜 | ✅ | 2026-10-04 |
| 금액 | ✅ | 12,000 |
| 통화 | ✅ (기본값 ₩) | ₩ / $ / ¥ |
| 원화 환산 금액 | 외화일 때 ✅ | ¥3,000 → ₩27,500 |
| 소항목 | ✅ | 식비 |
| 결제수단 | ✅ | 카드 / 현금 / 이체 + (카드·이체일 때) 카드사·은행 선택 |
| 메모 | 선택 | 스타벅스 |

사진(영수증)은 넣지 않아요.

## 8. 예산 바 색상 (지출)

내 기준은 **예산의 90%에 닿으면 이미 심각한 상태**예요. 그 전부터 경각심을 갖도록 색을 정해요.

| 사용률 | 색 | 의미 |
|---|---|---|
| 0 ~ 40% | 회색 | 여유 |
| 41 ~ 60% | 노랑 | 신경 쓰기 시작 |
| 61 ~ 89% | 주황 | 조심 |
| 90 ~ 100% | 빨강 | 심각 — 거의 다 씀 |
| 100% 초과 | **검붉은색 + "⚠ ₩○○ 초과" 문구** | 예산 넘음 |

- 초과하면 바는 꽉 찬 상태로 두고, 옆에 초과 금액을 글자로 보여줘요.
- 빨강과 검붉은색은 눈으로 구분하기 어려울 수 있어요. 그래서 **글자 표시가 핵심**이에요.

## 9. 화면에서 보고 싶은 것

1. **월 화면 (메인)**: 큰 분류 → 소항목별 금액, 예산, 색상 바
2. **월별 전체 내역 리스트**: 날짜순
3. **지난달과 비교**
4. **1년 요약**: 월별 합계
5. **그래프**
   - 카테고리별 비교 (막대)
   - 지출 비율 (원/도넛)
6. **결제수단별 지출 내역**

## 10. 내보내기

| 형식 | 내용 |
|---|---|
| **B5 PDF (출력용)** | 그 달의 **큰 분류 요약** + 지출 비율 **도넛 그래프** |
| **엑셀 (.xlsx)** | 파일 하나에 **월별로 탭(시트)**이 나뉨 — 구글시트에서도 열림 |

## 11. 통화

- 원화(₩), 달러($), 엔화(¥)를 지원해요.
- 통화가 다른 돈을 그냥 더하면 안 돼요. (₩10,000 + ¥1,000 ≠ 11,000)
- 그래서 **원화로 바꿔서 합쳐요.**
  - 외화로 쓰면 **원래 금액**(¥3,000)과 **원화 금액**(₩27,500)을 둘 다 저장해요.
  - 원화 금액은 환율로 자동 계산해서 채워줘요. 카드 청구액을 보고 직접 고칠 수도 있어요.
  - 예산 바, 합계, 그래프, 내보내기는 모두 **원화 금액 기준**으로 계산해요.
  - 내역에는 `¥3,000 (₩27,500)`처럼 둘 다 보여줘요.

## 12. 디자인 방향

- 앱 이름: **심플가계부**
- **범고래 캐릭터**에 맞춘 **흰색 / 검은색** 위주 (자세한 건 02-design)
- 깔끔하고 단순하게
- 아이폰 화면 기준으로 만들어요. 맥북에서는 아이폰 화면을 가운데에 그대로 보여줘요.

## 13. 기술 방향 (요약 — 자세한 건 04-tech에서)

- **순수 HTML / CSS / JavaScript + PWA**
  - 빌드 과정이 없어서 초보에게 쉬워요.
  - 아이폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요.
- 데이터: **Supabase** (로그인 + 데이터베이스)
- B5 출력: 브라우저 인쇄 기능으로 B5 크기 지정 → PDF로 저장
- 엑셀: 브라우저에서 바로 .xlsx 파일을 만드는 라이브러리 사용

## 14. 이번에 하지 않는 것

- 은행/카드사 자동 연동
- 영수증 사진
- 남은 예산 다음 달로 넘기기
- 여러 사람이 **한 가계부를 같이** 쓰기 (가입은 누구나 가능하지만 가계부는 각자)
