## 0. 이 문서에서 쓰는 말

- **표(테이블)**: 엑셀의 시트 하나라고 생각하면 돼요.
- **행**: 표의 한 줄. 예: 내역 표에서 "10/4 스타벅스 4,500원" 한 건
- **열**: 표의 칸 이름. 예: 날짜, 금액, 메모
- **앱 안에 넣어둔 목록**: Supabase에 저장하지 않고 앱 코드에 적어두는 고정 목록이에요. 소항목, 카드사, 은행이 해당돼요. 내가 바꿀 일이 없으니까 저장할 필요가 없어요.

| 규칙 | 내용 |
|---|---|
| 기록 시작 | **2026년 1월**부터 볼 수 있어요. (그 이전 달로는 이동하지 않음) |

### 2-2. 아이콘 이미지

- 직접 준 이미지를 써요. [assets/icons/](../assets/icons/)에 저장했어요.
- 768×768 PNG이고, **연회색 동그라미 배경이 그림에 포함**되어 있어요. 동그라미 바깥은 투명해요.
- 나중에 받은 7장(경조사, 모임, 패션, 자기계발, 여행, 기타 수입, 기타 지출)은 동그라미 크기나 위치가 조금씩 달라요. 특히 `etc-expense.png`는 동그라미가 왼쪽 위로 치우쳐 있어요. 개발할 때 크기와 가운데 위치를 맞춰요.

## 3. Supabase에 저장하는 표 (6개)

실제 만드는 SQL: [supabase/schema.sql](../supabase/schema.sql)

### 3-1. 내역 (`transactions`) — 가장 중요한 표

수입·지출 한 건이 한 줄이에요.

| 열 | 뜻 | 예시 |
|---|---|---|
| id | 내역 번호 (자동) | |
| user_id | 누구 데이터인지 (자동) | |
| date | 날짜 | 2026-10-04 |
| kind | 수입 / 지출 | 지출 |
| category | 소항목 | 간식 |
| currency | 통화 | JPY |
| amount | 원래 금액 | 3000 |
| krw_amount | **원화 금액** (모든 합계는 이걸로 계산) | 27500 |
| rate | 쓴 환율 (원화면 비움) | 9.1667 |
| pay_type | 카드 / 현금 / 이체 | 카드 |
| pay_org | 카드사·은행 (선택) | 신한카드 |
| memo | 메모 (선택) | 편의점 |
| source | 어떻게 들어왔는지 | 직접 / 자동 / 붙여넣기 |
| created_at, updated_at | 만든 때, 고친 때 (자동) | |

- 원화로 쓴 돈은 `amount`와 `krw_amount`가 같아요.
- **"내 기록에서 배우기"**(붙여넣기 자동 분류)는 이 표의 메모와 소항목을 보고 배워요. 그래서 따로 표가 필요 없어요.

### 3-2. 예산 (`budgets`)

| 열 | 뜻 | 예시 |

| category | 소항목 | 식비 |

### 3-4. 고정 항목 자동 기록 규칙 (`recurring_rules`)

| 열 | 뜻 | 예시 |

### 3-5. 자동 기록 실행 기록 (`recurring_runs`)

| 열 | 뜻 | 예시 |
|---|---|---|

- "이번 달 월세는 이미 자동으로 넣었다"를 기억하는 표예요.

- 아이폰과 맥북을 동시에 열어도 **두 번 기록되지 않아요.** (같은 규칙·같은 달은 한 줄만 허용)

## 4. 자동 기록은 어떻게 동작하나요?

서버가 없어서, **앱을 열 때** 확인해요.

```
앱을 엶
  → 자동 규칙을 하나씩 확인
     → "이번 달 기록 날짜가 지났나?"  아니오 → 홈에 "예정 25일"로 표시
                                    예 → "이번 달에 이미 넣었나?" (실행 기록 표 확인)
                                           예 → 아무것도 안 함
                                           아니오 → 내역 표에 한 줄 추가 + 실행 기록 남김
                                                   → 홈에 "완료 ✓"
```

- 예를 들어 월세가 25일인데 앱을 27일에 처음 열었어도, 내역에는 **25일 날짜로** 들어가요.
- 며칠 동안 앱을 안 열었다가 열어도 빠진 달을 모두 채워요. (규칙의 시작 달부터)
- 자동으로 들어간 내역도 일반 내역처럼 **날짜·금액을 고칠 수 있어요.**

## 5. 환율

- 외화를 입력하면 **쓴 날짜의 환율**을 인터넷에서 가져와 원화 금액을 채워요.
- 주말·공휴일은 환율이 없어서 **바로 전 영업일** 환율을 써요.
- 가져온 환율은 그 내역에 같이 저장해요. 나중에 환율이 바뀌어도 내 기록은 그대로예요.
- 카드 청구액이 다르면 원화 금액을 직접 고치면 돼요.
- 어떤 환율 서비스를 쓸지는 [04-tech.md](04-tech.md)에서 정해요. (무료, 키 필요 없는 곳으로)

## 6. Supabase가 잠들었을 때 깨우는 법

무료 버전은 **7일 동안 접속이 없으면** 잠들어요. 데이터는 그대로 남아 있어요.

1. [supabase.com/dashboard](https://supabase.com/dashboard)에 로그인
2. 가계부 프로젝트를 누르면 **"Paused"**(일시정지) 표시가 보여요.
3. **"Restore project"** 버튼 누르기
4. 몇 분 기다리면 다시 켜져요.

- 앱이 데이터를 못 불러오면 **"데이터베이스가 잠들었을 수 있어요"** 안내와 위 순서를 보여줄게요.
- 아주 오래(약 90일 이상) 잠들어 있으면 버튼으로 못 살릴 수도 있다고 해요. 매일 쓰시면 걱정 안 하셔도 돼요.

## 결정된 것 (2026-10-04)

- 소항목은 아이콘이 있는 27개만 넣어요. 공과금, 미용실처럼 목록에 없는 지출은 **기타 지출**에 넣어요.
- 이름: 모임, 패션, 자기계발, 카페·간식. 월세와 관리비는 따로 두고 같은 집 그림을 써요. 용돈은 부수입과 같은 그림을 써요.
- 결제수단: 카드 → 카드사, 이체 → 은행, 현금
