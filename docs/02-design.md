> 작성일: 2026-10-04

## 1. 디자인 원칙

- **범고래 캐릭터**에 맞춰 **흰색 배경 + 검은색 글자·버튼** 위주로 만들어요.
- 색은 **의미가 있을 때만** 써요.
  - 수입 = 초록
  - 지출 = 빨강
  - 예산 바 = 회색 → 노랑 → 주황 → 빨강 → 검붉은색 ([01-idea 8번](01-idea.md))
  - 저축 항목(💰) 바 = 초록
- 범고래는 **기분(상태)을 보여주는 역할**이에요. 홈 상태, 칭찬 팝업, 빈 화면 같은 곳에 나와요.
- 참고 앱: **머니차곡** ([스크린샷](images/reference-moneychagok.png))
  - 가져올 점:
    - 남은 예산을 크게 보여주는 카드
    - 오른쪽 위 상태 뱃지(안정)
    - 초록/빨강 수입·지출 버튼
    - 오늘 쓸 수 있는 돈
    - 캐릭터 인사 메시지
    - 달력에 날마다 쓴 돈 표시
    - 무지출 뱃지
  - 여러 줄 붙여넣기 자동 분류: AI 없이 2단계에 추가 (13번)
- 아이폰 화면 기준으로 만들어요. 맥북에서는 아이폰 크기 화면을 가운데에 그대로 보여줘요.
- "그 달"과 "오늘"은 항상 **한국 시간** 기준이에요.

### 색 정리 (초안)

| 이름 | 용도 | 색 |
|---|---|---|
| 배경 | 화면 바탕 | 흰색 `#FFFFFF` |
| 카드 | 영역 구분 | 아주 연한 회색 `#F5F5F7` |
| 기본 글자 / 버튼 | 글자, + 버튼, 선택된 탭 | 범고래 검정 `#1A1A1A` |
| 보조 글자 | 설명, 날짜 | 회색 `#8E8E93` |
| 수입 | 수입 금액 | 초록 |
| 지출 | 지출 금액 | 빨강 |

정확한 색 값은 개발할 때 화면을 보며 조정해요.

## 2. 화면 목록

| 화면 | 들어가는 방법 | 하는 일 |
|---|---|---|
| 로그인 | 앱을 처음 열 때 | 이메일 + 비밀번호 |
| **홈** | 하단 탭 | 이번 달 남은 예산, 상태, 소항목별 예산 바 |
| **내역** | 하단 탭 | 위 달력(날마다 쓴 돈, 무지출) + 아래 그날 내역, 골라보기, 수정·삭제 |
| **통계** | 하단 탭 | 그래프, 비교, 1년 요약, 결제수단별, 저축 쌓이기 |
| **설정** | 하단 탭 | 소항목 켜기/끄기, 고정 항목 자동 기록, 내보내기, 로그아웃 |
| 입력 | 오른쪽 아래 **⊕ 버튼** | 수입/지출 한 건 추가 |
| 예산 입력 | 홈의 "예산 입력" 버튼 | 그 달 소항목별 예산 |
| 월말 칭찬 팝업 | 달이 끝난 뒤 처음 앱을 열 때 | 지난달 결과와 칭찬 |

### 하단 탭바

```
┌──────────────────────────────┐
│   홈     내역     통계    설정   │
└──────────────────────────────┘
```

- 이모지 없이 **글자만** 넣어요. 선택된 탭은 검정 굵은 글씨, 나머지는 회색이에요.
- 입력은 탭이 아니라 **떠 있는 ⊕ 버튼**으로 해요. (아래 3-5)

## 3. 홈 (월 화면)

### 3-1. 전체 모습

```
┌──────────────────────────────┐
│       ◀   2026년 10월   ▶      │ ← 화살표 또는 좌우로 밀어서 달 이동
│                              │
│ ┌──────────────────────────┐ │
│ │ 남은 예산 (10/1~10/31) [주의]│ │ ← 오른쪽 위 상태 뱃지
│ │ ₩ 550,000       [범고래]  │ │ ← 크게
│ │                          │ │
│ │ [수입 +₩3,200,000] [지출 −₩1,450,000] │ ← 초록 / 빨강 버튼
│ │                          │ │
│ │ 예산 사용률 72%  ₩2,000,000│ │ ← 사용률 / 이번 달 총예산
│ │ ██████████████░░░░░░      │ │ ← 바 (01-idea 8번 색 규칙)
│ │                          │ │
│ │ 주의                      │ │ ← 상태 단어
│ │ 이번 주는 조금 아껴볼까요?    │ │ ← 짧은 메시지 (작게)
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 오늘 쓸 수 있는 돈  ₩19,000 │ │ ← 남은 예산 ÷ 남은 날 수
│ │ 남은 28일 기준             │ │
│ └──────────────────────────┘ │
│                              │
│ 수입              +₩3,200,000 │ ← 초록 (아래 합계)
│  ▸ 고정 수입        ₩3,000,000 │
│  ▸ 변동 수입          ₩200,000 │
│                              │
│ 지출              −₩1,450,000 │ ← 빨강 (아래 합계, 마이너스)
│  ▾ 고정 지출          ₩700,000 │
│     월세                 완료 ✓ │
│     ███████████████████████  │
│     적금💰  100%    ₩300,000  │
│     ███████████████████████  │ ← 초록
│  ▾ 변동 지출          ₩750,000 │
│     식비 80%      ₩30,000 남음 │
│     ██████████████████░░░░░  │
│                 예산 ₩150,000 │
│     간식 30%      ₩35,000 남음 │
│     ███████░░░░░░░░░░░░░░░░  │
│                  예산 ₩50,000 │
│                          (⊕) │ ← 입력 버튼
├──────────────────────────────┤
│   홈     내역     통계    설정   │
└──────────────────────────────┘
```

### 3-2. 위쪽 요약 카드 (한 영역)

| 순서 | 내용 | 계산 |
|---|---|---|
| 1 | **남은 예산** (가장 크게) + 상태 뱃지 | 이번 달 지출 예산 합계 − 이번 달 지출 합계 |
| 2 | 수입 / 지출 (초록·빨강 버튼, 누르면 내역으로) | 이번 달 합계 |
| 3 | 예산 사용률 %, 총예산 | 지출 합계 ÷ 지출 예산 합계 |
| 4 | 바 | 사용률만큼 채움 |
| 5 | **상태 단어** + 범고래 | 아래 표 |
| 6 | 짧은 메시지 (작게) | 아래 표 |

- 예산을 넘으면 남은 예산이 `−₩30,000 초과`처럼 빨간색으로 나와요.

**오늘 쓸 수 있는 돈** (요약 카드 아래 작은 카드)
- 계산: 남은 예산 ÷ 이번 달 남은 날 수 (오늘 포함)
- 예: 남은 예산 ₩550,000, 남은 날 28일 → **하루 ₩19,000**
- "앞으로 얼마나 쓸 수 있는지"를 가장 직관적으로 보여줘요.
- 계산할 때 **아직 안 나간 고정 지출(예정)**도 미리 빼요. 그래야 25일에 월세가 나가도 갑자기 줄어들지 않아요.
  - 정확한 계산: (남은 예산 − 이번 달 남은 고정 지출 예정액) ÷ 남은 날 수
- 지난달 이전 화면에서는 이 카드를 숨겨요.

### 3-3. 상태 단계 (4단계)

| 사용률 | 상태 단어 | 범고래 (예시) | 메시지 예시 |
|---|---|---|---|
| 0 ~ 60% | **안정** | 반짝이며 돼지저금통 안은 범고래 | "잘하고 있어요!", "이대로만 가요 🐳" |
| 61 ~ 89% | **주의** | 땀 흘리며 계산기 보는 범고래 | "조금씩 아껴볼까요?" |
| 90 ~ 100% | **위기** | 우는 범고래 | "위기! 남은 예산이 얼마 없어요" |
| 100% 초과 | **초과** | 돈이 날아가는 범고래 | "예산을 넘었어요. 다음 달엔 꼭!" |

> 💡 **속도 메시지 (제안)**: 사용률만 보지 않고 **"달이 얼마나 지났는지"와 비교**해서 메시지를 고르면 더 정확해요.
> - 예: 10일째인데(한 달의 33%) 사용률이 20% → "페이스 좋아요!"
> - 예: 10일째인데 사용률이 50% → "이 속도면 예산을 넘어요"
>
> 상태 단어는 사용률로 정하고, 메시지만 속도를 반영해요.

### 3-4. 아래쪽 수입 / 지출 목록

- **수입** (초록): 고정 수입 + 변동 수입 합계
- **지출** (빨강, 마이너스로 표시): 고정 지출 + 변동 지출 합계
- 고정 수입, 고정 지출 같은 묶음 제목을 누르면 **접히고 펼쳐져요** (▸ 접힘 / ▾ 펼침).
  - **제안**: 지출 묶음은 처음부터 **펼침**, 수입 묶음은 **접힘**
  - 이유: 예산 바를 보는 게 이 앱의 핵심이라서 지출은 펼쳐두고, 수입은 금액만 보이면 충분해서 접어둬요.
  - 마지막으로 접고 편 상태는 기억해요.

**소항목 한 줄 모양**

```
식비 80%            ₩30,000 남음   ← 이름 + 사용률 / 남은 돈 (가장 눈에 띄게)
███████████████████░░░░░          ← 바
                  예산 ₩150,000   ← 작은 회색 글씨
```

- 가장 중요한 숫자는 **"얼마 남았는지"**예요. 그래서 오른쪽에 크게 둬요.
  - 사용률은 이름 옆에 작게, 예산은 바 아래에 더 작게 둬요.
  - 쓴 돈(₩120,000)은 따로 쓰지 않아요. 예산 − 남은 돈으로 알 수 있고, 줄이 복잡해지기 때문이에요.
- 예산을 넘으면 오른쪽이 `⚠ ₩30,000 초과`(빨강)로 바뀌어요.
- 실제 화면에서 좁아 보이면 "예산" 줄을 빼요.
- 소항목을 누르면 그 항목의 이번 달 내역으로 이동해요. (내역 화면에서 그 항목만 골라 보이는 상태)
- **고정 지출(저축 💰 제외)**: 다 내서 100%가 되면 빨강이 아니라 **"완료 ✓"(검정)**으로 보여줘요.
  - 이유: 월세가 나가면 바로 100%가 돼요. 이건 위험한 게 아니라 정상이에요.
  - 나가기 전에는 **"예정 25일"**(회색)로 보여주고, 그날이 지나 기록되면 **"완료 ✓"**로 바뀌어요.
  - 고정 수입(월급)도 똑같이 "예정 25일" → "입금 완료 ✓"로 보여요.
  - 예산보다 더 나갔을 때만 "초과"로 보여줘요.
- **저축 항목(💰)**: 초록 바예요. 경고색을 쓰지 않아요.

### 3-5. 입력 버튼 (⊕)

- **오른쪽 아래**에 떠 있는 검정 동그라미 + 흰색 ＋
- 홈과 내역 화면에서 보여요.
- 오른쪽 아래로 정한 이유:
  - 오른손 엄지가 가장 쉽게 닿는 자리예요.
  - 하단 탭 4개를 좌우 균형 있게 둘 수 있어요.

### 3-6. 예산이 아직 없는 달

│   10월 예산이 아직 없어요    │
│   [ 예산 입력하기 ]          │

## 4. 입력 화면

**한 화면 안에 전부** 들어가게 만들어요. 스크롤하지 않아도 돼요.

```
┌──────────────────────────────┐
│  ✕        [ 수입 | 지출 ]       │ ← 기본값: 지출
│                              │
│            ₩ 12,000     [₩▾] │ ← 금액 (크게) / 통화 선택
│         (외화면) ≈ ₩27,500 ✎  │ ← 외화일 때만 보임, 눌러서 고침
│                              │
│  🍚    🍪    🎮    🎁    💊     │
│  식비  간식  여가  선물  건강     │ ← 소항목 아이콘 (좌우로 넘김)
│  💄    🚕    📱    🏠    ＋     │
│  뷰티  교통  통신  월세  추가     │
│                              │
│ [10/4 (토)] [카드·신한▾] [메모…] │ ← 날짜 / 결제수단 / 메모(선택)
│ ┌────┬────┬────┐             │
│ │ 1  │ 2  │ 3  │             │
│ ├────┼────┼────┤             │
│ │ 4  │ 5  │ 6  │             │
│ ├────┼────┼────┤             │ ← 숫자 패드
│ │ 7  │ 8  │ 9  │             │
│ ├────┼────┼────┤             │
│ │ 00 │ 0  │ ⌫  │             │
│ └────┴────┴────┘             │
│ [          저장          ]   │
└──────────────────────────────┘
```

- **수입 / 지출**: 맨 위 탭으로 골라요. 탭에 따라 아래 소항목 아이콘이 바뀌어요.
  - 수입 탭: 월급, 부수입 …
  - 지출 탭: 식비, 간식 …
- **소항목 아이콘**: 이모지가 아니라 **이미지**를 써요. 소항목은 앱이 정한 목록이라 아이콘도 앱이 하나씩 정해서 넣어둬요.
  - 이미지 출처는 [03-data.md](03-data.md)에서 정해요.
  - 위 그림의 🍚 같은 이모지는 자리 표시일 뿐이에요.
  - 아이콘 마지막 칸은 ＋ 대신 **[더 보기]**예요. 누르면 설정의 소항목 켜기/끄기로 가요.
- **숫자 패드**: 앱 안에 직접 만든 패드예요. 아이폰 키보드가 올라와서 화면을 가리지 않아요.
- **날짜**: 기본값은 오늘이에요. 누르면 달력이 나와요.
- **결제수단**: [카드 | 현금 | 이체] 중에서 골라요.
  - 카드나 이체를 고르면 **카드사·은행**도 골라요. (안 골라도 저장돼요)
  - 지난번에 고른 것이 기본값이에요.
- **메모**: 누르면 그때만 키보드가 올라와요.
- **저장하면**:
  - "저장했어요" 알림이 잠깐 떴다 사라져요.
  - 금액, 소항목, 메모는 비워지고 **날짜와 결제수단은 그대로** 남아요. (몰아서 입력하기 편하게)
  - ✕를 누르면 홈으로 돌아가요.

## 5. 내역 화면 (달력 + 아래 내역)

한 화면에 **위에는 달력, 아래에는 고른 날의 내역**이 보여요. 처음 열면 **오늘**이 골라져 있어요.

```
┌──────────────────────────────┐
│       ◀   2026년 10월   ▶      │
│ 수입 +₩3,200,000  지출 −₩1,450,000│
│ [전체 ▾] [결제수단 ▾]  🐳 무지출 5일│ ← 골라보기
│                              │
│ 일   월   화   수   목   금   토   │
│                   1    2    3   │
│                −7만  −2만  🐳    │ ← 날마다 쓴 돈 (빨강)
│  4    5    6    7    8    9   10  │
│ (−2만) +5만 🐳  −1만 ...          │ ← 수입은 초록, 고른 날은 검정 동그라미
│ ...                          │
│ ─────────────────────────────│
│ 10월 4일 (토)  −₩24,500  [이번 달 전체]│
│  🍚 식비  스타벅스  신한   −₩6,500│
│  🍪 간식  ¥3,000   현금 −₩27,500│
│                          (⊕) │
└──────────────────────────────┘
```

**달력**
- 날짜 칸마다 그날 쓴 돈을 **짧게**(−7만) 보여줘요. 수입이 있으면 초록으로 같이 보여줘요.
- 지출이 없는 날은 **무지출 🐳 표시**를 하고, 위쪽에 "무지출 N일"을 세어줘요. (오늘 이후 날짜는 세지 않아요)
- 고른 날짜는 검정 동그라미로 표시해요.

**아래 내역**
- 기본값: **고른 날(처음엔 오늘)의 내역**
- **[이번 달 전체]** 버튼: 그 달 내역을 날짜별로 묶어서 모두 보여줘요. 다시 날짜를 누르면 그날 내역으로 돌아가요.
- ⊕를 누르면 **고른 날짜로** 입력 화면이 열려요.

**골라보기** ([전체 ▾] = 소항목, [결제수단 ▾])
- 고르면 달력 숫자와 아래 내역 모두 그 조건으로 바뀌어요.
- 홈에서 소항목을 누르거나 통계에서 결제수단을 누르면, 그 조건이 걸린 채로 **[이번 달 전체]** 상태로 열려요.

**공통**
- **누르면 수정**: 입력 화면이 그 내용으로 채워져서 열려요.
- **왼쪽으로 밀면 삭제**: 바로 지워지지 않고 "삭제할까요?"를 한 번 물어봐요.
- 외화는 `¥3,000 (₩27,500)`처럼 둘 다 보여줘요.

## 13. 2단계 기능: 여러 줄 붙여넣기 입력

기본 기능을 다 만든 뒤에 추가해요. **AI는 쓰지 않아요.**

```
┌──────────────────────────────┐
│  ✕   여러 줄 입력               │
│ ┌──────────────────────────┐ │
│ │ 스타벅스 아메리카노 4500     │ │ ← 은행 앱에서 복사해 붙여넣기
│ │ 올리브영 화장품 32000       │ │
│ │ 택시 12000                │ │
│ └──────────────────────────┘ │
│        [ 자동 분류하기 ]        │
│ ─────────────────────────────│
│ 3건 자동 분류                   │
│  ₩4,500   🍪 간식 ▾  스타벅스…   │ ← 틀리면 눌러서 고침
│  ₩32,000  💄 뷰티 ▾  올리브영…   │
│  ₩12,000  ❓ 분류 안 됨 ▾ 택시   │ ← 모르면 내가 고름
│ [날짜 10/4] [결제수단 신한▾]      │
│        [ 3건 저장 ]             │
└──────────────────────────────┘
```

**분류하는 방법**
1. 줄마다 1건으로 나누고, 그 줄의 숫자를 금액으로 읽어요. 나머지 글자는 메모가 돼요.
2. 소항목은 아래 순서로 맞혀요.
   - **내 기록에서 배우기**: 예전에 같은 단어(예: "스타벅스")가 들어간 내역을 어느 소항목에 넣었는지 보고 그대로 따라가요.
   - **키워드 사전**: 위에서 못 찾으면 기본 사전(예: 택시 → 교통)을 봐요.
   - 둘 다 없으면 **"분류 안 됨"**으로 두고 내가 골라요.
3. 확인 화면에서 고친 내용은 다음 번 "배우기"에 쓰여요.
4. 버튼 위치: 입력 화면 오른쪽 위에 [여러 줄] 버튼

- 은행 앱에서 복사되는 글자 모양(날짜, "원" 등)은 실제 예시를 받아서 맞춰요.
